# 📦 SmartStock – Inventory & Sales Analytics System

SmartStock is a **MongoDB-based inventory and sales management system** built using Python and Streamlit. It provides an interactive dashboard for managing products, sales, suppliers, stock movements, and business analytics.

## 🛠️ Technologies

* Python
* Streamlit
* MongoDB
* PyMongo
* Pandas
* Plotly

## ✨ Features

* 📊 Interactive dashboard
* 📦 Product & inventory management
* 🧾 Sales management
* 🚚 Supplier management
* 🔄 Stock IN/OUT tracking
* 📈 Sales and inventory analytics
* 🔁 MongoDB CRUD operations
* ⚡ Automatic inventory updates

## 🗄️ MongoDB Collections

* `products`
* `sales`
* `suppliers`
* `stock_movements`

## ▶️ Run the Project

Install the required libraries:

```bash
pip install pymongo==3.12.3 pandas streamlit plotly
```

Start MongoDB on port `27018`, then run:

```bash
streamlit run app.py
```
